# N8N on Railway

Deploy n8n workflow automation platform to Railway with free tier.

## Quick Deploy

1. Push this repository to GitHub
2. Connect your GitHub account to Railway
3. Select this repository
4. Railway will automatically detect and deploy n8n

## Environment Variables

Set these in Railway dashboard:

- `N8N_USER`: Your admin username (default: admin)
- `N8N_PASSWORD`: Your admin password (default: password)
- `TIMEZONE`: Your timezone (default: America/New_York)

## Features

- ✅ Free tier hosting on Railway
- ✅ Automatic HTTPS
- ✅ Persistent data storage
- ✅ Webhook support
- ✅ Basic authentication

## Access

Once deployed, access n8n at your Railway URL with the credentials you set.
